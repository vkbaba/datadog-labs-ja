このラボでは、ダッシュボードの概要を簡単に学びます。

**学習目標**:

* すぐに使えるダッシュボードからウィジェットをコピーする
* ダッシュボードに追加する新しいウィジェットを作成する
* ダッシュボードのレイアウトをカスタマイズする

環境の準備ができたら、下の **Start** ボタンをクリックしてください。

## ダッシュボードについて

ダッシュボードは、グラフやウィジェットと呼ばれるその他のコンテナを永続的に配置し、共有できるものです。これまでのラボでも、すでにいくつかのウィジェットをダッシュボードに追加してきました。

このラボでは、プリセットのウィジェットをコピーする方法、ウィジェットを追加する方法、そしてダッシュボードを見やすくレイアウトする方法を学びます。

### ダッシュボードについて

このラボでは、新しいダッシュボードがあらかじめ作成されています。この新しいダッシュボードは **[Dashboard List](https://app.datadoghq.com/dashboard/lists)** で確認でき、`Datadog 101: SRE Dashboard` という名前が付いています。

:::note
ダッシュボードが作成されていない場合は、次のコマンドを実行してください。
```bash
python3 /root/setup.py
```
:::

## プリセットウィジェットをコピーする

1.  Datadog アプリで、**[Dashboards &gt; Dashboard List](https://app.datadoghq.com/dashboard/lists)** に移動します。

    PostgreSQL、Python、Ruby、Docker などのインテグレーションと一緒にインストールされた、多数のプリセットダッシュボードがあることに気づくはずです。

2.  **Docker - Overview** ダッシュボードをクリックします。

    :::note
    **Docker - Overview** ダッシュボードが表示されない場合は、別のプリセットダッシュボードと、そのダッシュボード内のウィジェットを使用してかまいません。
    :::

3.  下にスクロールして **Most RAM-intensive containers** ウィジェットを見つけます。ウィジェットの上にカーソルを合わせ、Cmd/Ctrl+C を押してウィジェットをコピーします。ダイアログが表示されます。

    ![ウィジェットのコピーダイアログ](/datadog-labs-ja/assets/cert01-datadog-fundamentals-prep/copying_widget_from_preset.png)

4.  **Done** をクリックし、画面下部にクリップボードのインジケーターが表示されることを確認します。

    ![クリップボードのインジケーター](/datadog-labs-ja/assets/cert01-datadog-fundamentals-prep/clipboard_indicator.png)

5.  インジケーターをクリックしてクリップボードを表示します。Datadog 全体のグラフ、ウィジェット、その他のコピー可能なリソースはここに集められ、Notebooks や Dashboards など別の場所で利用できます。

    クリップボード右上の **x** をクリックして閉じます。

6. Dashboard List に戻り、`Datadog 101: SRE Dashboard` というタイトルのダッシュボードを見つけます。

7. Cmd/Ctrl+V を押して、コピーしたウィジェットを貼り付けます。ダッシュボードの一番下に表示されます。

8. ダッシュボード上部のスターアイコンをクリックすると、後で簡単にここに戻ってこられます。

9. ダッシュボードの名前を変更したい場合は、タイトルをクリックしてから **Edit** ボタンをクリックし、好きな名前に変更します。

10. **Save** ボタンをクリックし、ESC を押してダッシュボードの詳細パネルを折りたたみます。

## ウィジェットを作成する

1. ダッシュボードで、中央に **+** がある空の **Add widgets** の四角をクリックします。

2. ウィジェットのサイドパネルから **List** ウィジェットを選択します。ウィジェットを絞り込むには、パネル上部のフィールドに `list` と入力します。

3. セクション 2 で、issues ではなく `Logs` を選択します。

4. **Search query** フィールドに、次のクエリを貼り付けます。

    ```bash
    service:discounts-service -status:info env:dd101-sre
    ```

    このクエリは、Logs のラボで作成したものと似ています。discounts サービスのエラーと警告をグラフ化します。

5.  **Give your graph a title** の下に、次の内容を入力します。

    ```bash
    Discounts Service Error Logs
    ```
6.  List Editor のモーダルは次のように表示されるはずです。

    ![Discounts のエラーログウィジェット](/datadog-labs-ja/assets/cert01-datadog-fundamentals-prep/discounts_error_logs.png)

6.  **Save** ボタンをクリックします。

新しく作成したウィジェットがダッシュボードに表示されるはずです。

最後に、前のラボで作成した SLO を追加します。

1.  ウィジェットのサイドパネルから **SLO** ウィジェットを選択します。ウィジェットリストを絞り込んで見つけやすくできます。

1.  **Select an SLO** の下で、ドロップダウンから `SLO: Discounts service request time` を選択します。

1.  **Set Time Windows** で、少なくとも 1 つの期間を選択します。

1.  **Widget title** の下に、次の内容を入力します。

    ```bash
    SLO: Discounts service request time
    ```

1.  **Save** ボタンをクリックします。

1.  ESC を押すか、右上の **X** をクリックしてウィジェットパネルを閉じます。

このダッシュボードには多くのウィジェットが並びました。次のセクションでは、これをより見やすく整えていきます。

## ダッシュボードを見やすくする

便利なウィジェットがいくつか揃ったので、これらを配置し、グループ化し、見やすく整えていきましょう。ウィジェットは自由にドラッグ＆ドロップしたり、サイズを変更したりできます。

いくつかのヒント:

-   ダッシュボードの空いている場所からクリック＆ドラッグすると投げ縄ツールが有効になり、複数のウィジェットを一度に選択できます。
-   Shift を押しながらクリックして、複数のウィジェットを選択することもできます。
-   複数のウィジェットを選択した状態で、表示される **Group** ボタンをクリックするか、Cmd/Ctrl+G を押すと、それらをグループ化できます。
-   グループには凝ったタイトルを付けられます。
-   ウィジェットのタイトルを変更できます。

このダッシュボードをレイアウトする際のおすすめの方法は次のとおりです。

1.  Docker のウィジェットと `Log count by service...` ウィジェットをグループ化し、次のタイトルを付けます。

    ```bash
    Systems
    ```

2.  `trace.flask.*` のウィジェットをグループ化し、次のタイトルを付けます。

    ```bash
    Flask request time
    ```

3.  discounts サービスの SLO とログストリームをグループ化し、次のタイトルを付けます。

    ```bash
    Discounts service
    ```

ダッシュボードを次のような見た目にしてみてください。

![完成したダッシュボード](/datadog-labs-ja/assets/cert01-datadog-fundamentals-prep/dashboard_complete.png)

これが最高のデザインのダッシュボードとは言えないかもしれませんが、繰り返し改善していくための良い出発点になります。

ダッシュボードは更新したりクローンしたりできるほか、JSON としてエクスポートしてハードディスクや Git リポジトリに保存することもできます。
